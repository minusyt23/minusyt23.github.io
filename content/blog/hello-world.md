First post on the new setup. The site runs on Hugo with the Hextra theme,
which covers both the [docs](/docs) section and this blog from a single
codebase.

<!--more-->

## Why this stack

- Static output, nothing to run in production
- Full-text search built into the theme, no external service
- Docs and blog share one navigation, one style, one build

Builds happen in GitHub Actions and deploy straight to GitHub Pages.
